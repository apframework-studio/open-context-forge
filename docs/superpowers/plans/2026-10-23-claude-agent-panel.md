# Claude 智能体协作与蓝白界面实施计划

日期：2026-10-23

## 本轮目标

在现有本机工作台加入可选择的智能体方案，先以当前 Claude CLI 完成真实对话验证，并将界面调整为蓝白商务配色。DeepSeek 只显示未配置状态；不接入 DeepSeek Harness。

## 方案

1. 服务端维护智能体方案清单。自动寻找本机 Claude CLI；读取可选的 `OCF_DEEPSEEK_API_KEY` 和 `OCF_ANTHROPIC_API_KEY` 环境变量，但不会向浏览器返回密钥。
2. 定义独立的 `AgentRunner` 接口。本轮由 Claude CLI 实现，使用 `claude -p --output-format json`、关闭内置工具，并通过 Claude session ID 续接。后续可将运行器替换为 ACP 客户端，而不改变文章和对话接口。
3. 对话按文章保存于 SQLite。每轮发送当前文章和来源摘录，回答作为建议保存；智能体无权直接写入文章或 vault。用户在原有编辑器中修改并定稿。
4. 右栏展示方案选择、状态、历史、提问输入和错误。仅文章工作台启用讨论。
5. CSS 改为浅蓝、白色、深蓝导航，改善卡片与输入对比度，并检查窄屏布局。

## 验证

- 先写服务端测试：方案发现与未配置状态、对话持久化和续接、错误与非法输入。
- 运行全部测试、类型检查与构建；使用本机 Node 22，避免现有 better-sqlite3 ABI 不匹配。
- 用实际 Claude CLI 发出最小一轮提问，确认鉴权和响应格式。
- 页面以浏览器或截图检查桌面与窄屏布局。
