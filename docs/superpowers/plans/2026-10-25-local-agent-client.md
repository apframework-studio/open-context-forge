# 本机智能体客户端实施计划

**目标：** 复用现有 Codex、Claude 运行器，在文章工作台提供真实流式输出、工具过程、权限交互、停止与切换后恢复，不编写自主规划或工具循环。

**已确认设计：** 本机 Fastify 作为连接服务；优先使用 ACP 官方 TypeScript SDK 和现成 Codex/Claude 适配器。文章及修订仍由产品管理。WorkBuddy 的本地助理需开放平台授权，本轮不把它显示为已可用。本机登录信息不传给浏览器，不自动安装全局工具，不修改用户全局智能体配置。

**执行方式：** 当前对话、当前 `codex/workflow-v1` 分支逐任务实施，保留之前所有未提交修改。

## 任务 1：验证协议与运行器

- [x] 核对并安装 ACP SDK、现成适配器；固定项目依赖，避免每轮 npx 下载。
- [x] 新增 ACP 连接模块：初始化、会话创建/恢复、消息增量、工具更新、权限请求、中断及子进程回收。会话恢复不支持时明确报错，不静默丢失历史。
- [x] 使用可控的真实 stdio 子进程测试消息分片、文本/工具事件、取消和错误。保留来源分析现有运行器接口。

## 任务 2：服务端持久运行

- [x] 新建 `agent_runs`、`agent_run_events`，保存用户消息、部分回答、执行状态和权限选项；一次每篇文章至多一个运行。
- [x] `POST /articles/:id/agent/runs` 接受任务并立即返回；`GET /articles/:id/agent` 返回历史及当前/最近运行；SSE 提供带序号的最新完整快照，重连时恢复最新状态，原始增量另存事件表。
- [x] 停止、权限答复接口检查文章和运行归属；不把离开页面当作取消。重启时保留输出，将未结束任务标记中断，避免自动重复执行副作用。
- [x] 兼容旧 `/agent/messages` 调用；旧问答历史保持可读。
- [x] 测试立即返回、增量可见、刷新恢复、同文章排他、文章隔离、取消、失败、重启以及权限重复答复。

## 任务 3：文章对话体验

- [x] 切换到运行接口与可恢复快照的 SSE；切换文章/方案清理订阅，所有异步结果按会话隔离。
- [x] 回复逐步显示；执行过程折叠展示真实工具名称、状态、结果；需要用户选择时在当前对话呈现权限按钮。
- [x] 提供停止、失败/中断后重试、耗时与连接状态；未完成内容不被当作完整文章自动采纳。
- [x] 保留现有蓝白紧凑布局、专注对话、正文采纳确认；窄屏不溢出。
- [x] 浏览器验证流式输出在完成前可见，切换/刷新恢复，停止生效，文章不串话，权限可答复。
